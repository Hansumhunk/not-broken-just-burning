# Not Broken Just Burning

Official website and digital platform for the **Not Broken Just Burning** movement.

## Mission

Build a public platform rooted in lived experience, emotional healing, spiritual awareness, psychological truth, reclamation, and purpose.

## Current version

Version 0.1 begins as a lightweight static site using:

- HTML
- CSS
- Vanilla JavaScript

This keeps the first release fast, understandable, inexpensive to host, and easy to evolve.

## Structure

```text
index.html
css/
  style.css
js/
  main.js
```

## Publishing guardrails

Source material may include books, manuscripts, curricula, courses, paid resources, merchandise concepts, and other future commercial intellectual property.

**Do not publish commercial source material merely because it exists in project storage.** Paid or unpublished material should only be added to the public website when it is intentionally prepared for release.

The public site should initially focus on:

- Mission and movement identity
- Public-facing story and philosophy
- Educational concepts intentionally selected for public release
- Future public articles and videos
- Community and contact pathways

## Planned expansion

Later versions may add dedicated pages for stories, resources, videos, community, events, newsletter functionality, commerce, books, courses, and other digital tools when those components are ready.
