H.A.W.K. Dashboard

Coordinate your existing offline files. See what is loaded, review your own next actions, and check references without changing the original records.

Privacy and safety: This dashboard can hold sensitive material from several tools at once. It does not upload, sync, automatically store, encrypt, contact anyone or assess your situation. Exports and printouts are readable. Use secure storage and a suitable device; avoid shared or monitored devices. Immediate danger requires local emergency services, not this tool. In the U.S., call 911 for emergencies or call/text 988 for emotional or suicide crisis support. No legal, financial, clinical or emergency service is provided.

1. Load your own saved files

Open one standalone version 1 JSON file at a time, or a complete dashboard workspace. A standalone file replaces its own module only; a workspace replaces all loaded modules, including clearing absent ones. No merge or automatic updates. Every file is validated before replacement. Save work first.

These permissions apply to the next import and reset after use. A workspace containing a sensitive module requires its explicit permission; otherwise the entire import is rejected.

Limits: 1,000 records per module; 100 MiB standalone files (support 32 MiB, communication 256 KiB); 128 MiB workspace. No documents or attachments. The dashboard is a read-only snapshot, not the original editor.

2. Module overview

Counts describe loaded records, not case readiness, credibility, relationship quality, legal or financial outcomes. A loaded empty module is distinct from a module not loaded.

3. Reference review

Checks compare IDs against the selected snapshots only. The timeline's free-text references are searched for complete E- tokens; legacy aliases and other unstructured text are not interpreted. No evidence authentication or inferred links. Sensitive communication references count only; their text never appears.

This view displays record IDs only. Not present does not mean nonexistent; choose current exports. Communication review relationships are included by ID only.

4. Your recorded next actions

Optional screen-only view of existing user-entered next actions and questions, not new advice. Closed checklist and court entries are excluded; other entries are not interpreted as outstanding obligations. Review against original tools and independently verify dates. Communication drafts and support notes are never displayed here.

5. Save selected modules or return to individual editors

Individual exports preserve each standalone format. Workspace export bundles selected loaded modules only. Sensitive communication and support are unchecked by default; explicitly select them only if appropriate. Export does not create an encrypted backup. Printed summary contains counts and reference totals only, not working text.

Reopen the original tool using its standalone JSON export to edit a record, then import its new snapshot here. No edits are made by this dashboard.

Educational organization only. Offline dashboard version 1.0. No legal assessment, risk score, automated judgment, reminders, cloud storage or recovery service.
