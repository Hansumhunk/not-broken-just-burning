Future Account Bridge · Development Mockup

The door between the public site
and the member platform.

These are layout and workflow mockups only. Authentication is not connected, and these fields intentionally do not accept real credentials.

Do not enter a real password here. The controls below are disabled because this development branch is designing the user experience before Supabase Auth or another authentication provider is connected.

Returning member

Sign in

Future behavior: authenticate, restore a secure session, then route to the Flamewalker Dashboard.

New member

Create account

Future behavior: create the auth identity, verify email if required, create the minimal profile record, then enter onboarding.

Account recovery

Reset access

Future behavior: the authentication provider handles recovery tokens and password resets. NBJB never sees a plaintext password.

3 · Member

Enter the Hub

The dashboard loads only profile/progress data the signed-in member is permitted to read.

Authorization matters too

Login is not the same thing as permission.

The future database must use Row Level Security or equivalent server-side authorization so one member cannot read another member's records. Paid or private content needs an entitlement check before it is returned. Hiding a link does not count as security, despite the internet's long and embarrassing history of trying.
