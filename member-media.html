Delivery rule

YouTube can attract attention. The member library holds the learning system.

The public YouTube channel can use trailers, excerpts, introductions, and selected clips to help people discover NBJB. Full member lessons should not depend on public or merely unlisted URLs as the access-control mechanism.

Future protected video should use a host/delivery method that supports authenticated or signed member access. Large video files do not belong in this public GitHub repository.
