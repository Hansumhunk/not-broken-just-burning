## Negative-case coverage and limitations

Failed permission attempts, invalid signatures and scope mismatches result in `AccessDenied`. DB constraint violations for immutable original rows are deliberately enforced by SQLite triggers; a privileged local admin can still modify triggers. Atomic transaction interruption tests verify rollback of SQLite changes; export crash-window tests verify pending-export cleanup on next open, **not** guaranteed zero exposure during the interval before cleanup. Manifest HMAC detects changes made without the backup secret, but a signer/host administrator can rewrite the manifest and local hash chain: **no independent witness or external anchor**.

No production access-control row, storage policy, hosted restore, operational owner identity or commercial release gate was tested. No test creates a public file or a live connection to Supabase, Brevo, Stripe or member accounts.
